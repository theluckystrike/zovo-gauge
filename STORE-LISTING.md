# Store listing draft

## Title

Zovo Gauge

## Summary

See visible engagement signals before you choose what to watch.

## Detailed description

Gauge turns page-visible likes and views into an honest likes-per-view engagement
rate. A compact chip sits on home, feed, search, grid, compact, and reel
thumbnails. When a score is not available yet, the chip says so instead of
inventing one; open the video once and Gauge can reuse the visible score during
the current browser session.

Choose a quality threshold to dim low-engagement thumbnails. Pro users can
collapse them completely. Hover a measured chip to see an estimated visible
likes-per-day rate based on the upload age shown on the page.

The popup is a private session scorecard: sort videos by engagement, likes per
day, or recency, then jump back to any measured item. The ledger uses session
storage and disappears with the browser session. There is no dislike-data lookup
and no server round-trip for scores.

Features:

- likes-per-view engagement chips across browsing surfaces;
- adjustable pre-watch quality filter;
- visible likes-per-day hover estimate;
- sortable session-local ranking;
- clear unknown state when the page does not expose enough numbers; and
- local settings with no account required.
